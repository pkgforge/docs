# Packages

Portable package formats for GUI applications:

- [AppImage](appimage/) - Single-file portable applications
- [AppBundle](appbundle/) - Portable app bundles
- [FlatImage](flatimage/) - Flatpak-based portable images
- [RunImage](runimage/) - Container-based portable apps
- [NixAppImage](nixappimage/) - Nix-based AppImages
- [Archive](archive/) - Compressed archives

## Troubleshooting

See [Errors & Quirks](errors-and-quirks/) for common issues (FUSE, fonts, namespaces).
