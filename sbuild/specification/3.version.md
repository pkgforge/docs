# 3.Version

```yaml
pkgver: "1.2.3"
```

* [x] Fixed version of the package (**TYPE:** <mark style="color:green;">**`RECOMMENDED`**</mark>)
* [x] Use `pkgver: "--"` to dynamically fetch version via `x_exec.pkgver` (for auto-updates)

{% hint style="info" %}
When `pkgver` is set to a fixed value, `x_exec.pkgver` is still used to check for updates but the fixed version takes precedence for builds.

Use `pkgver: "--"` when you want the version to always be fetched dynamically from `x_exec.pkgver`.
{% endhint %}
