# PkgForge-Dev

[PkgForge-Dev](https://github.com/pkgforge-dev) hosts development and experimental projects, most of them concerned with making upstream applications portable enough to package.

Its AppImage builds are where a good part of soarpkgs' `appimage` packages come from, in cases where upstream publishes no AppImage of its own or publishes one that only works on the distribution it was built on.

## Projects

* [Anylinux-AppImages](projects/anylinux-appimages.md), AppImages that run on any Linux distribution
