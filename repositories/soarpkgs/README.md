# soarpkgs

[Soarpkgs](https://github.com/pkgforge/soarpkgs) is the official package repository for Soar. It contains [SBUILD](../../sbuild/introduction.md) recipes that define how packages are built.

## Structure

- **SBUILD recipes**: Build scripts in YAML format
- **bincache**: Prebuilt static binaries
- **pkgcache**: Prebuilt GUI applications (AppImages, etc.)
