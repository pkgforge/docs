# Security

- All packages are reviewed before inclusion
- Unofficial packages are [forked](https://github.com/orgs/pkgforge-community/repositories?q=fork%3Atrue+archived%3Afalse) to preserve history
- SBUILD requires [source](../../sbuild/specification/18.sourceurl.md) links for transparency
- Unofficial packages include a [note](../../sbuild/specification/15.note.md) indicating community origin
